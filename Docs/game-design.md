# Luna & Stella's Potion Shop — 게임 기획서

> NHN AI Game Hackathon 사전 과제 source of truth.
> 변경 시 CLAUDE.md 요약도 같이 업데이트.

---

## 1. 개요

- **장르**: 싱글플레이 매치3(Match-3) 퍼즐
- **레퍼런스**: 애니팡 (인접 타일 교환 → 3개 이상 매치)
- **목표**: 매치3 MVP 완성 (NHN AI Game Hackathon 사전 과제 제출)
- **플랫폼**: 웹 (Unity WebGL) — GitHub Pages 배포. PC 실행파일(.exe) 제출 불가(대회 규정)
- **개발 기간**: 사전 과제 제출 기한(2026.08.10)까지 약 2주, 1인 개발

## 2. 세계관 / 톤

- **배경**: 견습 마녀 **루나**가 별빛 상점에서 물약 재료를 매치하는 코지 판타지
- **아트 스타일**: 16-bit 코지 픽셀아트 (Cozy Fantasy RPG Asset Pack — 파스텔톤, 진한 보라 아웃라인)
- **캐릭터**: 루나(Luna, 마녀), 스텔라(Stella, 검은고양이) — 2종만 (스코프 확정, §8 참고)
- **분위기**: 아늑하고 따뜻함, 어둡거나 무서운 톤 지양

## 3. 핵심 재미

세 줄로 정의:
1. **인접한 물약 재료 타일을 교환**해 같은 모양 3개 이상을 맞춘다
2. 매치 시 **점수 획득 + 연쇄(캐스케이드)로 콤보** 발생
3. **정해진 이동 횟수 안**에 최고 점수/최고 콤보를 노린다

## 4. 게임 루프

```
게임 시작 (스테이지 1의 LevelData → 그리드 초기화)
 ↓
[메인 루프] 타일 선택 → 인접 타일과 교환 → 매치 판정
             → (매치 성립) 점수 획득 + 재료 수집(주문 진행) → 캐스케이드(낙하 채움) → 연쇄 매치 판정
             → (매치 실패) 원위치로 되돌림, 이동 횟수는 소모하지 않음(§3 참고)
 ↓
스테이지 주문(재료 요구량) 완료 → 스테이지 클리어 → 다음 스테이지로 진행
   또는
이동 횟수(스테이지별 설정, 기본 20회) 소진(주문 미완료) → 게임 오버
 ↓
결과 화면 (최종 점수 + 최고 콤보) → 재시작   ※ 미구현, §9 참고
```

- **마이크로 루프** (초 단위): 타일 선택·교환·매치 판정
- **메조 루프** (여러 수): 캐스케이드·콤보 누적·주문 진행
- **매크로 루프** (스테이지 1개): 주문 완료 또는 이동 횟수 소진까지
- **캠페인 루프** (여러 스테이지): `StageSequence`를 따라 스테이지를 연속 진행 (`feature-spec/11-order-stage.md`)

## 5. 조작

- **입력**: 마우스 클릭(또는 터치) — 타일 선택 후 인접 타일 클릭 시 교환 시도
- 교환 결과 매치가 성립하지 않으면 **원위치로 되돌리고 이동 횟수 미소모** (신규 Input System 기반, `Docs/feature-spec/01-input.md` 참고)

## 6. 재료(타일) 종류 — 6종 기본값

> "자연 재료"(버섯/꽃/잎/열매 등) 컨셉에서 보석 컨셉을 거쳐, **"숲/동굴에서 채집하는 마법 재료"** 컨셉으로 확정. 이유: 실제 아이콘 아트를 Cainos Pixel Art Icon Pack에서 확보하면서, 물약 재료로 자연스러운 것(과일/버섯/젤리/원석) 위주로 맞춤 — 보석 일색보다 코지한 "채집" 톤에 더 가까움 (`Docs/asset-credits.md` 참고).

| 재료 | 색상(참고용) | 아이콘 출처 |
|---|---|---|
| 흑요석 조각 | 짙은 남색 | Cainos Obsidian |
| 빨간 사과 | 빨강 | Cainos Apple |
| 이끼 방울 | 초록 | Cainos Slime Gel |
| 달빛 버섯 | 탠/브라운 | Cainos Mushroom |
| 마법 수정 | 청록 | Cainos Crystal |
| 요정 깃털 | 크림/화이트 | Cainos Feather |

※ 여섯 번째 슬롯은 토파즈(버섯과 갈색 겹침) → 횃불(무기/도구 느낌이라 컨셉과 안 맞음) → 맥주(재료라기보다 완성 음료라 컨셉과 안 맞음) → 요정 깃털로 최종 교체 — 6개 중 유일한 밝은 톤(크림/화이트)이라 명암 대비가 가장 좋음.
※ "색상" 열은 설명용일 뿐 코드 필드가 아님 — `IngredientData.colorTag`는 렌더링/로직 어디에서도 쓰이지 않는 죽은 필드라 2026-08-02 코드에서 제거함 (타일 정체성은 스프라이트만으로 표현).

타일 종류 수는 하드코딩하지 않고 설정값으로 관리 (`Docs/convention.md` §1). 스테이지(`LevelData`)마다 재료 배열을 다르게 구성할 수 있음 — 위 표는 기본 스테이지 구성 기준.

## 7. 점수 / 콤보

- 매치 1건당 기본 점수 부여, 매치 타일 수가 많을수록(4개, 5개 등) 가산
- 캐스케이드로 연속 매치 발생 시 **콤보 카운트 증가** → 콤보별 점수 배율(세부 수치는 `Docs/feature-spec/04-score-combo.md`에서 확정)
- 결과 화면에 **최종 점수 + 최고 콤보 수** 표시 (§9)

※ 콤보 카운트/배율 로직은 아직 미구현ㄴ. 현재는 캐스케이드 단계 깊이에 비례한 점수 배율만 적용됨 — `04-score-combo.md` 참고.

## 8. 명시적 비스코프

사전 과제 스코프 **밖**:
- 타이머 기반 종료 (이동 횟수 제한만 사용)
- 인게임 옵션 메뉴, 다국어
- 모바일 네이티브 빌드 (WebGL로 모바일 브라우저 커버, 별도 APK는 선택)
- 스테이지/맵 선택 화면 (순서대로만 진행), 전체 캠페인 클리어 시의 별도 엔딩 연출

※ 스테이지 진행/주문 시스템과 특수 타일은 2026-08-02부로 정식 스코프에 포함됨(기존엔 비스코프였음). §4, `feature-spec/11-order-stage.md`, `feature-spec/12-special-tiles.md` 참고.

## 9. 결과 화면

- 표시: 최종 점수, 최고 콤보 수
- "다시 시작" 버튼 1개

※ 미구현 (2026-08-02 기준). 현재는 스테이지 클리어 시 "수집 완료!" 배너 + "다음 스테이지로" 버튼, 이동 횟수 소진 시 "수집 실패..." 배너만 있고 이 화면 자체가 없음. 대회 심사 필수 항목이므로 4단계 작업으로 반드시 채울 것 — 게임 오버 시점(및/또는 전체 스테이지 클리어 시점)에 노출하는 방식으로 설계 필요.
