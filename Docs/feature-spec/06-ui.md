# 6. UI

## HUD (인게임)
- 상단 바(화면 폭 전체): 현재 점수(실시간 갱신, `ScoreChangedChannel` 구독) 바로 오른쪽에 잔여
  이동 횟수(`MovesChangedChannel` 구독, 2026-08-04부터 여기로 이동 — 이전에는 미션 패널에 있었음)를
  나란히 배치, 좌측에는 현재 스테이지 번호("스테이지 N" 형태의 단순 증가 카운터, 2026-08-03 추가)
  — `Match3Controller`가 `SetupLevel`마다 `GameManager.CurrentStageNumber`를 읽어
  `PuzzleHud.UpdateStageLabel`을 직접 호출(이벤트 채널 아님, `PuzzleSidePanel.SetIngredientSprites`와
  같은 이유 — 레벨 설정값이라 채널 타이밍과 안 맞음). `CurrentStageNumber`는 실제 `StageSequence`
  길이와 무관하게 스테이지를 클리어할 때마다(마지막 스테이지 반복 플레이 포함) 계속 늘어나는
  카운터이지 "N/전체" 형태가 아님 — 총 스테이지 수를 보여주는 개념 자체가 없음. `GameManager`가
  없는 단독 씬 테스트 환경에서는 표시하지 않음.
- 보드 옆 미션 패널(`PuzzleSidePanel`): 주문 진행도를 요구사항(최대 3종)당 한 줄씩 "아이콘 ×
  남은 개수" 형식으로 표시(`OrderProgressEventChannel` 구독, 2026-08-04 갱신 — 이전에는 남은
  개수만큼 아이콘을 grid로 늘어놓았음). 아이콘 크기는 튜토리얼 안내 패널(`TutorialPanel`)의 물약
  아이콘과 같은 비율을 써서 동일한 픽셀 크기로 보인다(두 패널이 보드를 사이에 두고 서로 대칭되는
  같은 크기이기 때문)
- 콤보 최댓값 추적(`GridController.MaxCombo`), 결과 화면 노출, 그리고 "Combo x{n}!" 팝업 텍스트
  연출까지 **구현 완료**(2026-08-03) — 액션 하나에서 매치 스텝이 2개 이상 이어졌을 때만(콤보 정의는
  `04-score-combo.md`) 보드 중앙에 금색 텍스트로 뜬다(`PuzzleHud.AnimateComboPopup`,
  `Match3Controller.OnSwapPlaybackComplete`가 `StartCoroutine`으로 구동). 콤보 규모에 비례해 최종
  크기가 커지고(3개 매치=1.0배, 4개=1.15배, 5개 이상=1.3배), 그 크기까지 ease-out-back으로 살짝
  튀어오르듯 팝인(0.2초)된 뒤 유지(0.8초)되다 축소+페이드로 사라진다(0.2초, 2026-08-04 갱신 — 그냥
  뜨고 사라지는 것보다 동적으로 보이도록). 팝업이 끝나기 전에 다음 콤보가 또 발생하면 이전
  애니메이션을 멈추고 새로 시작한다(`Match3Controller._comboPopupCoroutine` 참고).

## 스테이지 전환 배너 (구현 완료)
- 주문 완료: 보드 위에 "클리어!" 배너 + "다음 스테이지로" 버튼(`PuzzleHud`) → 클릭 시 `GameManager.AdvanceStage()`로 다음 `LevelData` 로드
- 이동 횟수 소진(주문 미완료): "게임 오버" 배너 표시 — 아래 결과 화면 내용을 포함
- `NoteController`(노트북 페이지 슬라이드 연출, 클리어한 스테이지 목차 누적)는 구현되어 있으나 아직 어디서도 호출되지 않음 — 결과 화면/스테이지 요약 화면을 설계할 때 활용 후보로 남겨둠

## 결과 화면 (Result) — 구현 완료, 대회 심사 필수 항목
- 게임 오버(이동 횟수 소진, 주문 미완료) 시 `PuzzleHud.ShowGameOver(finalScore, maxCombo)`가
  같은 배너에 다음을 표시: **최종 점수**, **최고 콤보 수**, "다시 시작" 버튼
- "다시 시작" 클릭 → `restartRequestedChannel` Raise → `Match3Controller.OnRestartRequested`가
  `GameManager.ResetProgress()` 후 첫 스테이지로 보드 재구성(씬 리로드 없이 같은 퍼즐 씬 안에서
  진행, `08-intro-title.md` 참고)

## 플레이 방법 안내 패널 (구현 완료, 2026-08-04)
- 미션 패널(`PuzzleSidePanel`)이 보드 오른쪽의 빈 여백에 자리하는 것과 대칭되게, 보드 왼쪽의
  같은 크기 빈 여백에 상시 표시되는 자체 패널(`TutorialPanel`)로 구현 — 퍼즐 패널을 가리지 않음
- 내용: 매치3 기본 규칙 한 줄 + 특수 타일(물약) 생성/활성화 방법 한 줄 + 물약 3종(행/열/범위
  폭탄) 각각의 아이콘과 효과 — 종류별 설명은 `12-special-tiles.md` 참고
- `PuzzleSidePanel`과 동일한 스타일(어두운 반투명 배경, `Match3Controller.Start()`에서 `transform.parent`(PuzzleCanvas)를 부모로 생성) — 모달이 아니라 게임 내내 떠 있는 참고용 패널이라 열고 닫는 상태나 확인 버튼이 없음(2026-08-04: 기존 "화면 전체 Dim + 시작하기 버튼" 모달 방식에서 전환)

## 배경 (구현 완료)
- Menu/Main 씬 공통으로 보라빛 숲/별/버섯 연못 컨셉의 배경을 사용
- 정적 이미지(`Background.png`)가 아니라 64프레임 시퀀스(`Assets/Art/Sprites/UI/Blackground/u1.jpg`~`u64.jpg`, 별빛 반짝임/꽃잎 낙하/수면 파문 연출)를 `FlipbookAnimator`(`Assets/Scripts/Common/FlipbookAnimator.cs`, 캐릭터 애니메이션과 동일 컴포넌트 재사용)로 재생 — 원래 스펙은 "여유 있으면 정적 이미지로 교체"였으나, 사용자가 애니메이션 프레임을 직접 준비해 스트레치 목표를 상회하는 결과물로 대체함(2026-08-02)
- 마지막(64) → 처음(1) 프레임으로 바로 되돌아가면 색감이 튀는 문제가 있어, `frames` 배열 자체를 1→64→63→...→1(총 127프레임) 왕복 순서로 구성해 재생 — 코드 수정 없이 데이터 배열만으로 핑퐁 루프 구현, 연속 프레임끼리만 이어지고 루프 지점(1→1)도 같은 프레임이라 끊김이 없음
- 배경 스프라이트 원본 해상도(1280x720)가 카메라 화각(orthographic size 5, 16:9)보다 작아 `Background` 오브젝트 스케일을 1.1 → 1.44로 조정해 화면을 가득 채우도록 함
- **보드/UI 레이어보다 아래 Sorting Layer**(`Background`, Sorting Order -100)에만 배치, 인터랙션 없음
