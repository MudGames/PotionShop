# 6. UI

## HUD (인게임)
- 상단 바(화면 폭 전체): 현재 점수만 표시 (실시간 갱신, `ScoreChangedChannel` 구독)
- 보드 옆 미션 패널(`PuzzleSidePanel`): 주문 진행도(재료별 남은 개수를 스와치로 표시, `OrderProgressEventChannel` 구독) + 잔여 이동 횟수(`MovesChangedChannel` 구독)
- 콤보 발생 시: 보드 위쪽에 "Combo x{n}!" 텍스트가 짧게 팝업 후 페이드아웃 (선택, 폴리싱 단계) — ※ 콤보 로직 자체가 미구현이라 현재는 표시 불가 (`04-score-combo.md` 참고)

## 스테이지 전환 배너 (현재 구현)
- 주문 완료: 보드 위에 "클리어!" 배너 + "다음 스테이지로" 버튼(`PuzzleHud`) → 클릭 시 `GameManager.AdvanceStage()`로 다음 `LevelData` 로드
- 이동 횟수 소진(주문 미완료): "게임 오버" 배너만 표시, 재시작 버튼 없음 (아래 결과 화면 참고)
- `NoteController`(노트북 페이지 슬라이드 연출, 클리어한 스테이지 목차 누적)는 구현되어 있으나 아직 어디서도 호출되지 않음 — 결과 화면/스테이지 요약 화면을 설계할 때 활용 후보로 남겨둠

## 결과 화면 (Result) — 미구현, 대회 심사 필수 항목
- 표시해야 함: **최종 점수**, **최고 콤보 수**
- "다시 시작" 버튼 1개
- ※ 현재는 위 "스테이지 전환 배너"만 있고 이 화면 자체가 없음. 게임 오버 시점(그리고/또는 전체 스테이지 클리어 시점)에 노출할지 설계 필요 — 4단계 작업

## 인트로/타이틀

## 배경 (스트레치 목표)
- 기본: 단색 또는 그라디언트
- 여유 시간 있으면: 업로드된 참고 이미지(보라빛 나무, 별/달 장식 상점) 스타일의 정적 배경 이미지로 교체
  - 이 경우도 **보드/UI 레이어보다 아래 Sorting Layer**(`Background`)에만 배치, 인터랙션 없음

## 캐릭터 배치 (연출용, 선택)
- 루나(Luna, 마녀)와 스텔라(Stella, 검은고양이)를 화면 가장자리에 Idle 애니메이션으로 배치해 분위기 보강 (게임플레이에는 관여하지 않음)
- 매치 발생 시 루나가 짧게 반응하는 정도는 스트레치 목표 (Idle 유지 + 스케일 pulse 정도로 애니메이션 추가 없이 구현)
