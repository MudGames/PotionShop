# 12. 특수 타일 (Special Tiles / 물약)

> 2026-08-02 정식 스코프 편입. 기존 `02-board-tile.md`/`03-match-cascade.md`의 "여유 시간 스트레치 목표" 방침 대체.
> 2026-08-04 재설계: 기존 `ColorBomb`(컬러 폭탄)을 제거하고 행/열/범위 3종으로 재정리 — 아래 "2026-08-04 재설계" 절 참고.

## 종류 (`SpecialKind`)
| 종류 | 생성 조건 | 활성화 효과 |
|---|---|---|
| `LineRow` | 가로 4개 매치 (run의 가운데 셀에 생성) | 그 **행** 전체 제거 |
| `LineColumn` | 세로 4개 매치 (run의 가운데 셀에 생성) | 그 **열** 전체 제거 |
| `RadiusBomb` | 가로/세로 5개 이상 매치, 또는 가로+세로 매치가 교차(L자/T자)하는 지점 | 중심 기준 3x3 범위 제거 |

- 생성 규칙 우선순위: 길이 4(행/열 판정) → 길이 5+ → 교차. 5+ 규칙과 교차 규칙은 결과적으로 같은
  `RadiusBomb`을 만들 뿐이라 서로 충돌하지 않는다. 상세는 `SpecialTileResolver.Plan` 참고
- 특수 타일로 확정된 셀(anchor)은 그 매치 스텝에서 제거되지 않고 보드에 남는다
- **특수 타일은 매치 대상이 아니다(2026-08-03 확정)**: 이미 만들어진 특수 타일은 색깔이 같아도
  `MatchDetector`가 런에 끼워주지 않는다 — 캐스케이드 중 우연히 같은 색 사이에 끼여도 조용히
  사라지지 않고 그대로 남아, 오직 아래 "활성화 방법"(직접 스왑/탭)으로만 사라진다. 다른 폭탄이
  터져서 그 효과 범위 안에 있는 연쇄 폭발은 별개(계속 자동으로 일어남).

## 2026-08-04 재설계 — 컬러 폭탄(ColorBomb) 제거
기존에는 5칸 이상 매치가 "보드 전체에서 같은 재료를 전부 제거"하는 `ColorBomb`을 만들었다. 하지만
활성화되는 순간 배지가 재료 아이콘을 완전히 덮어버려서, 그 폭탄이 "어떤 재료"를 기억하고 있는지
플레이어가 알 방법이 없다는 근본적인 문제가 있었다 — 즉 효과 자체가 플레이어에게 불투명했다.
`ColorBomb`을 완전히 제거하고, 5칸 이상 매치는 대신 `RadiusBomb`을 만들도록 대체했다("긴 매치 =
더 강한 보상" 설계 의도는 그대로 유지). 동시에 `LineRow`/`LineColumn`이 공유하던 배지도 서로 다른
색으로 분리해서(아래 "비주얼" 참고), 활성화 전에도 행 폭탄인지 열 폭탄인지 구분할 수 있게 했다.

## 활성화 방법
- 특수 타일을 인접 타일과 교환(swap) → 즉시 활성화, 이동 횟수 소모
- 특수 타일을 단독으로 탭 → 즉시 활성화, 이동 횟수 소모 (`GridController.TryActivateSpecial`)
- 활성화된 특수 타일의 효과 범위 안에 다른 특수 타일이 있으면 연쇄 폭발(chain reaction)한다 — 안전장치로 보드 크기 기준 반복 상한을 둠(`SpecialTileResolver.ExpandWithChainReactions`)

## 콤보 결합 (두 특수 타일을 서로 swap)
| 조합 | 효과 |
|---|---|
| Line + Line(행/열 무관) | 두 지점 모두 십자(행+열) 제거 |
| RadiusBomb + RadiusBomb | 두 지점 모두 반경 5x5로 확대 제거 |
| RadiusBomb + Line | Line 방향으로 3줄(두꺼운 라인) 제거 |

## 점수/주문 연동
- 특수 타일 폭발에 휩쓸려 제거된 **일반 타일**은 일반 매치 제거와 동일하게 점수 및 주문(Order)
  수집 개수에 반영됨
- **특수 타일 자신**은 별개의 타일로 취급되어(2026-08-04 확정), 터지는 순간에도 밑에 깔린 재료
  색상 기준의 주문 수집에는 반영되지 않는다 — 점수(`PointsPerTile`)는 계속 그대로 반영됨
  (`GridController.ResolveOneStep` 참고)
- 특수 타일 자체(anchor)가 생성되는 셀은 "제거"가 아니므로 그 타일의 점수/수집 집계에는 포함되지 않음 (다음 폭발 때 집계됨)

## 비주얼 (2026-08-04 갱신)
