# 1. 입력 (Input)

> 마우스/터치 기반. 신규 Input System 사용 (convention §7).

## 동작
- **교환 시도(드래그 한 번으로 완결, 2026-08-04)**: 타일 A에서 인접한(상하좌우) 방향으로 드래그하면
  드래그가 끝난 지점의 우세한 축/방향으로 목표 타일 B를 계산해 즉시 교환 시도한다(대각선 없음,
  `TileView.OnDragEnded`/`BoardView.TileSwiped` 참고). 셀 크기의 30% 미만으로 짧게 움직인 드래그는
  실수로 스친 것으로 보고 무시한다 — 기존의 "첫 탭으로 A 선택 → 인접한 B를 탭해 교환" 두 번 클릭
  방식을 대체함(첫 탭 방식은 스페셜 타일 종류를 구분하기 전 임시 구현이었음). 드래그 중 시작
  타일에 뜨던 원형 선택 링 하이라이트는 제거함(2026-08-04) — 어떤 타일을 선택 중인지 굳이 표시하지
  않아도 드래그 미리보기(아래 항목)만으로 충분하다는 판단.
- **드래그 중 스왑 미리보기(2026-08-04 추가)**: 드래그하는 동안 타일 A가 우세한 축/방향으로 손가락을
  따라 미리 이동하고, 그 방향의 인접 타일 B는 반대로 같은 만큼 밀려나 마치 서로 자리를 바꾸는
  도중처럼 보인다(`TileView.OnDragging`/`BoardView.OnViewDragPreview` 참고). 이동 폭은 셀 크기
  한 칸으로 제한된다(그 이상 끌어도 더 밀리지 않음). 드래그 도중 방향을 바꾸면 이전에 밀어뒀던
  이웃은 즉시 제자리로 되돌아가고 새 방향의 이웃이 대신 밀린다. 놓았을 때 임계값(30%)을 넘겼고
  보드 범위 안이면 미리보기 위치에서 그대로 이어받아 기존 교환 애니메이션(성사/거부 포함)이
  재생되고, 임계값 미만이거나 보드 밖이면 둘 다 즉시 원위치로 되돌아간다(`TileView.DragCanceled`/
  `BoardView.OnViewDragCanceled` 참고). 캐스케이드 애니메이션 재생 중에는 미리보기 자체가 시작되지
  않는다(`BoardView.InputEnabled`가 `TileController.Enabled`와 함께 꺼짐 — 그렇지 않으면 애니메이션
  도중 시작된 드래그가 조용히 무시된 채 미리보기 위치에 어긋나 남을 수 있다). 미리보기가 한 칸만큼
  (진행률 100%) 완전히 밀렸는데 그 조합이 매치를 만들지 못한다면, 손을 놓기 전이라도 즉시 강제로
  드롭되어 거부 애니메이션(교환 시도 후 원위치로 되돌림)이 재생된다(`GridController.WouldAcceptSwap`/
  `TileView.ForceDragEnd` 참고) — 매칭도 안 되는데 완전히 스왑된 것처럼 보이는 상태로 무한정
  붙잡고 있을 수 있었던 문제를 막기 위함. 칸의 배경(빈 슬롯)은 말(재료 아이콘/스페셜 배지)과 분리된
  고정 레이어라 미리보기/스왑/캐스케이드 애니메이션 내내 전혀 움직이지 않는다(`BoardView.
  CreateBackgroundGrid` 참고, §`02-board-tile.md`).
- **일반 타일 탭(드래그 아님)**: 교환을 시도하지 않고 선택 사운드만 재생(`TileController.TileSelected`)
- **스페셜 타일 탭(드래그 아님)**: 그 자리에서 즉시 활성화(`TileController.SpecialActivationRequested`)
  — 드래그로 스페셜 타일을 인접 타일과 교환해도 동일하게 활성화된다(`GridController.TrySwap`의
  `activatesSpecial` 처리, 방향과 무관)
- **드래그 제스처 중 탭 오인 방지(`TileDragInput`, 2026-08-04 추가)**: 같은 제스처에서 드래그가 이미
  시작됐다면 그 뒤에 이어지는 탭(`OnPointerClick`)은 무시한다 — 없으면 스페셜 타일을 옮기려는
  드래그가 동시에 탭으로도 인식돼, 옮기려던 자리(원래 위치)에서 즉시 활성화돼 버리는 문제가 있었다
  (일반 타일은 탭 결과가 선택음 재생뿐이라 티가 안 났지만, 스페셜 타일은 제자리에서 바로 터지는
  것으로 눈에 띄었음 - "행/열 폭탄을 옮기면 이동 중에 터진다"는 버그 리포트로 발견)
- **UI 버튼**: 결과 화면 "다시 시작" 버튼은 마우스 클릭

## 결과 처리
- 교환 후 매치 성립 → `03-match-cascade.md` 로직 실행, 이동 횟수 1 소모
- 교환 후 매치 불성립 → 타일 원위치 애니메이션(짧게, 예: 0.15초) 후 되돌림, **이동 횟수 미소모**
