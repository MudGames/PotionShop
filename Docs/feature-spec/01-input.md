# 1. 입력 (Input)

> 마우스/터치 기반. 신규 Input System 사용 (convention §7).

## 동작
- **타일 선택**: 첫 클릭(또는 탭)으로 타일 A 선택 (선택 표시: 살짝 확대 + 테두리 하이라이트)
- **교환 시도**: 이어서 **A와 인접한(상하좌우) 타일 B**를 클릭 → 두 타일 위치 교환 시도
  - 인접하지 않은 타일 클릭 시: A 선택 해제, 새로 클릭한 타일을 A로 재선택 (교환 시도 없음)
- **드래그 방식(선택/확장)**: 타일을 인접 방향으로 드래그해도 동일하게 동작 — 최소 구현은 클릭-클릭 방식으로 먼저 완성 후 여유 있으면 드래그 추가
- **UI 버튼**: 결과 화면 "다시 시작" 버튼은 마우스 클릭

## 결과 처리
- 교환 후 매치 성립 → `03-match-cascade.md` 로직 실행, 이동 횟수 1 소모
- 교환 후 매치 불성립 → 타일 원위치 애니메이션(짧게, 예: 0.15초) 후 되돌림, **이동 횟수 미소모**

## 비스코프
- 키보드 조작, 게임패드 지원
- 멀티터치/제스처(핀치 줌 등)
