# 7. 게임 사운드 (Sound)

> 게임플레이가 아니라 폴리싱 단계(개발 순서 5단계 이후)에서 붙인다.

## SFX (트리거 ↔ 필요 파일)
| 트리거 | 비고 |
|---|---|
| 타일 선택 | 짧고 가벼운 톤 |
| 교환 성공(매치) | 매치 개수 3/4/5+에 따라 피치 살짝 다르게(선택) |
| 교환 실패(매치 없음) | 부드러운 "안 됨" 톤, 부정적이지 않게 |
| 캐스케이드 연쇄 | 콤보 카운트 증가마다 재생, 겹치면 최근 것만 |
| 라운드 종료 | 1회 |

- AI 생성 SFX 또는 무료 CC0 라이브러리 사용 시 출처를 AI 활용 기술 문서에 기록 (CLAUDE.md 참고)
- 동시 다발 시 볼륨/피치 랜덤 소폭 적용(단조로움 방지, 선택)

## BGM
- 인게임 루프 BGM 1트랙 (코지 톤, 잔잔한 템포)
- 타이틀 화면: 동일 트랙 또는 무음

## 구현
- `AudioSource.PlayOneShot` 수준의 단순 재생. 전용 매니저는 필요 시 가벼운 `SfxPlayer` 정도.

## 비스코프
- 다이나믹 믹싱, 음량 옵션 메뉴
